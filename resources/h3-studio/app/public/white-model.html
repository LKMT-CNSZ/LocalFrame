附加工具 · 三维模型预览

支持 GLB、GLTF、OBJ、STL。GLTF 请同时选择 .bin 与贴图；OBJ 仅导入几何。不支持 Draco 压缩、SKP、FBX，请先导出为 GLB。文件仅在本机读取，单个模型 ≤ 100MB，总计 ≤ 200MB。

材质与光照

标准渲染为本地 WebGL/PBR 实时渲染，不是离线路径追踪。输出不会改变模型文件。

AI 效果图 · 兼容图像编辑 API
