# LocalFrame 影像创作

LocalFrame 是一款 Windows 桌面影像创作工具，把图片、视频、分镜和后期制作放在一个工作空间里。你可以在本机运行模型，也可以接入自己使用的在线服务，从创意草稿一直做到成片归档。

## 能做什么

- **视频创作**：支持 MiniMax H3 本地文生视频、参考图生视频和首尾帧控制；也可配置 MiniMax、可灵、即梦或豆包等在线服务。
- **分镜与项目**：从创意、剧本和角色设定整理镜头，按镜头生成、保存进度并合成视频。较长的任务可以在镜头完成后安全暂停，之后继续。
- **图片与白模**：使用兼容的本地图片模型生成画面；导入三维模型预览，或将白模视频逐帧转换为指定风格。
- **配音与字幕**：通过本地语音引擎制作中文配音，编辑对白时间轴，混合环境声并导出字幕和成片。
- **基础版与专业版**：基础版提供直接操作的创作界面；专业版连接 ComfyUI 节点画布，适合需要调整工作流的用户。
- **资源管理**：查看任务状态和硬件使用情况，按项目整理生成结果。运行环境和模型可以在部署中心单独安装或修复。

## 使用前准备

- Windows x64。运行本地视频模型需要兼容的 NVIDIA 显卡、足够的显存、内存和磁盘空间；不同配置的速度与画质会有明显差异。
- 本仓库不包含 H3 等大型模型权重、ComfyUI 或完整的推理环境。安装和首次配置相关组件需要联网；环境准备完成后，本地生成可离线运行。
- 在线服务需要自行配置账号、接口权限和凭据，费用与可用功能以服务提供商为准。平台协作模式需要使用对应平台的网页。
- 白模视频逐帧处理可能出现闪烁或细节变化；模型生成结果也需要人工检查与调整。
- 使用声音参考素材前，请确认已获得相应授权。

## 从源码运行

准备 Windows、Node.js 22.12 或更新版本和 npm，然后在项目目录中运行：

```powershell
npm ci
npm start
```

运行测试：

```powershell
npm test
```

构建 Windows 安装程序：

```powershell
npm run dist
```

安装程序输出到 `release/`。源码构建不会自动提供大模型及其运行环境。Real-ESRGAN 增强组件的可执行文件与权重也未放入本仓库；如需使用，可自行准备兼容版本，并将路径配置为 `LOCALFRAME_REALESRGAN_EXE`。

## 项目结构

```text
src/                  Electron 主进程与桌面界面
resources/h3-studio/  创作服务、页面、部署脚本和工作流
scripts/              开发与构建辅助脚本
tests/                自动化测试
assets/               应用图标与图形资源
packaging/            安装包附带说明
```

## 第三方组件

LocalFrame 使用 Electron、ComfyUI、CosyVoice、Three.js 等项目，并包含部分第三方节点及其版权文件。各组件、模型和服务分别适用自己的许可证或使用条款；使用或再分发前请查看对应项目的许可说明。仓库中 `resources/h3-studio/bundled-nodes/` 包含的节点保留了原有许可证和版权声明。
