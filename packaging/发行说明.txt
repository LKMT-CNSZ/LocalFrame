1.4.1 白模标准渲染与 AI 效果图
- 顶部新增“白模渲染”入口，可导入 GLB、GLTF、OBJ、STL；GLTF 可同时选择配套 .bin 和贴图。
- 三维文件仅在本机浏览器内存中解析，不会因预览或标准渲染上传；单个模型限制 100MB，所选附件总计限制 200MB，超过 200 万三角面会拒绝载入。
- 提供透视、正面、侧面、顶视相机，白色石膏、混凝土、金属、陶土和原材质选择，以及颜色、粗糙度、灯光、旋转和背景调整。
- 标准渲染使用本地 WebGL/PBR，可导出 1024 方图、1080P、2K 横屏或 2K 竖屏 PNG；这是实时光栅渲染，不虚构为离线路径追踪。
- AI 效果图使用用户自行配置、支持参考图的兼容 `/v1/images/edits` 接口；只上传点击生成时的当前视角 PNG 和提示词，不上传三维文件。
- 每次 AI 生成前必须明确勾选上传与可能计费确认；API Key 仅保留在当前页面内存，页面离开时清空，不写入设置。
- 远程 API 强制 HTTPS，不跟随重定向，不自动重试以避免重复计费；只接受直接返回 PNG Base64 的接口，拒绝外部图片链接。
- AI 可能改变白模几何细节，因此界面明确标注效果图不能作为精确施工图；SKP、FBX 与 Draco 压缩 GLB 暂不直接支持。
- 桌面运行时升级到 Electron 44.4.5；npm 依赖审计为 0 个已知漏洞。

1.4.0 视频服务模型探测与超分稳定性
- 根据官方地址识别视频服务，并尝试读取模型列表；可从列表选择模型和对应的原生画质参考档位。
- 模型列表只表示服务列出的模型，账号生成权限与实际输出画质需由真实生成验证；未开放枚举接口时显示未验证参考清单。
- 鉴权或连接失败明确报错；变更 API 来源时不复用旧密钥，拒绝携带凭据跨来源重定向。
- 提交时校验分辨率、时长、首尾帧能力；MiniMax Hailuo 02 的 1080P 档仅允许 6 秒。
- 修复 FlashVSR 在中文路径下的 Triton 缓存错误和后端退出码 0 假成功问题。
- FlashVSR 极短样本完成真实 4 倍超分验证：256×160 到 1024×640、2 帧、24fps，并恢复音轨。该结果不代表长视频或 2K 稳定性已经验证，仍作为实验档开放。
- 超分封装保留源帧率，严格检查帧数；修复极短视频因音轨长度导致尾帧丢失。

1.3.9 2K 交付与 AI 二次画质修复
- H3 原生高质量画布与交付分辨率正式分离：LocalFrame 不再把插值输出描述为 MiniMax H3 原生 2K。
- 新增 2K 横屏 2560×1440、竖屏 1440×2560、方形 2048×2048 交付规格。
- 新增三档可选后处理：Lanczos 高清还原、Real-ESRGAN 帧级 AI 二次推理、FlashVSR 视频扩散二次采样实验版；默认全部关闭。
- 全工作流和基础版均可选择二次修复后端与快速、均衡、细节优先策略；未安装后端时明确提示，不会偷偷降级。
- FlashVSR 固定采用 256 像素分块与 64 像素重叠，避免旧 128/24 参数造成棋盘格；低显存模式按短分块运行。
- AI 修复只在 H3 完成全部短分镜与合片后启动；启动前确认 ComfyUI 队列为空并释放驻留模型，避免显存竞争。
- 保留 H3 原生成片作为回退文件；AI 输出完成后校验分辨率、帧数、时长、帧率与音轨，截断或丢音轨会判定失败。
- 安装包内置官方 Real-ESRGAN Vulkan 便携后端及 BSD-3-Clause 许可证；FlashVSR 约 7GB 权重不随主安装包自动下载，只检测用户已有环境。

1.3.8 全工作流角色三视图定妆
- 全工作流新增独立“角色定妆”阶段，支持为多位角色分别上传正面、侧面和背面全身参考图。
- 每位角色可填写脸型、发型、体型、服装、配色和标志性配件等锁定说明；三张图齐全后才能确认角色模型。
- 三视图原图、角色说明和确认状态随项目保存在本机；替换图片或修改说明后会自动要求重新确认。
- 已确认的角色模型会写入后续导演分镜的人物连续性约束，减少跨镜头外观漂移。
- 新增三视图文件类型、单图 15MB 上限、路径隔离、项目序列化与图片读取回归测试。
- 六步全工作流导航及角色卡片已完成桌面与窄屏适配。
- 默认把剧情拆成约 5 秒的独立短分镜，每个镜头使用不同动作与构图单独采样、校验和缓存，再优先通过 FFmpeg 流复制无损拼接，避免末帧续接导致后续镜头重复循环。
- 用户可自行选择内部生成画质、4–12 步采样、3–10 秒自动分镜时长，以及“独立短分镜”或“末帧续接”策略。
- 新增“纯画面无音轨”与“环境声”选择；纯画面模式会在交付前物理移除模型音轨，杜绝生成角色念台词。
- 加强视频模型提示词：人物嘴唇闭合、不做说话口型，禁止手机屏幕/招牌等文字载体进入画面，并禁止字幕、可读字符、复演、倒放与相邻镜头循环。

1.3.7 基础版跳步与快速启动
- 修复基础版使用 H3 Lite W4A8 组件集时 Spectrum 一键跳步没有接入工作流的问题；保守、均衡和最大跳步现在会真实作用于采样模型链。
- 安装包内置 Spectrum v0.2.27 源码组件；软件发现节点缺失时会自动补齐到现有 ComfyUI，不覆盖用户已安装的版本。
- 基础版冷启动只载入 ClipProj 与 Spectrum 两个实际需要的自定义节点，跳过 KJNodes、MAINodes、Manager 等专业节点扫描。

- 打开专业版时仍会切换到完整节点模式；若基础版正在生成或排队，软件会拒绝重启，避免中断任务。
- 新增 W4A8 跳步模型链、节点自动补齐与精简启动参数的回归测试。

1.3.6 AI 成片秒级台词轴
- “字幕与多角色声音轴”已从全工作流移到后期台；全工作流只负责剧本、分镜、画面和原生环境声。
- 后期台读取所选成片的真实时长，由已连接的文字模型生成精确到秒的台词、说话人、对白/旁白类型和角色声线。
- 每条台词可独立修改开始/结束秒数、说话人、类型、文字和声线；时间轴自动排序、裁剪越界并避免片段重叠。
- 新增“一键生成配音并烧录字幕”：逐条使用指定声线合成，按秒对齐，与原环境声混音后烧录中文字幕。
- 未连接文字模型或同机视频任务仍在运行时，自动使用本地时间轴兜底，且不会中断正在生成的视频。
- 修复用户编辑时间轴后角色声线元数据丢失的问题，并保证语音合成失败时清理临时 WAV。
- 字幕背景现在可调到 0% 全透明；默认烧录只显示字幕文字，不显示黑色背景框。

1.3.5 画面与后期声音分层
- 视频生成阶段只产出画面、环境声、动作声和必要的无歌词音乐，不再自动混入台词或旁白。
- 本地 H3、云端 API 和平台协作统一执行“无台词、无可读字符”的生成约束，并保留原生环境音轨。
- 后期台新增“同步生成并混入台词”，可使用项目角色声线或默认声线，与字幕一次渲染成片。
- 字幕背景不透明度最低为 25%；界面滑杆和后端 ASS 生成同时校验，旧项目传入全透明值也会自动修正。
- 多镜头平台视频合片时保留各镜头环境音；个别无音轨镜头使用静音段对齐，不再整片丢失声音。
